### Input Data Help

This section allows you to input time and yield data for COM analysis.

#### Mathematical Formulas

The extraction yield can be modeled using various equations:

**Linear Model:**

$$y = mx + b$$

**Exponential Model:**

$$Y(t) = Y_{\infty} \left(1 - e^{-kt}\right)$$

where:
- $Y(t)$ is the yield at time $t$
- $Y_{\infty}$ is the maximum yield
- $k$ is the extraction rate constant
- $t$ is the extraction time

**Power Law Model:**

$$Y = at^b$$

#### Inline Math

You can also use inline math like $\alpha = 0.05$ or $\beta = \frac{1}{2}$.

#### Complex Equation Example

The specific extraction cost can be calculated as:

$$SC = \frac{C_{total}}{Y_{extract}} = \frac{C_{RM} + C_{utilities} + C_{labor} + C_{fixed}}{Y_{extract}}$$

#### Greek Letters and Symbols

- Temperature: $T = 40°C$
- Pressure: $P = 300$ bar
- Density: $\rho = 0.8$ g/cm³
- Efficiency: $\eta = \frac{Y_{actual}}{Y_{theoretical}} \times 100\%$
