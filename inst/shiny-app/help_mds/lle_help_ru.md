## Жидкостно-жидкостная экстракция

Инструмент проектирует и ранжирует растворители для **извлечения целевого вещества из исходной (разбавляющей) фазы** — например, для извлечения ароматического, лекарственного или природного соединения из водного потока. Всё рассчитывается по молекулярной структуре с помощью нативной модели коэффициентов активности **COSMO-SAC-dsp** (экспериментальные данные о распределении не требуются) и применимо к **любой молекуле, которую можно нарисовать**, благодаря встроенному предсказателю σ-профилей.

Доступны **два режима анализа**: быстрый **скрининг** ранжирует растворители по коэффициенту распределения, а строгий **двухфазный расчёт** решает реальное жидкость-жидкостное равновесие — разделяет питание на две реальные фазы, распределяет каждое вещество между ними, выдаёт взаимную растворимость двух растворителей и оптимизирует по температуре (аналог AMS «Optimize LLE»).

### Физика

Вещество распределяется между двумя контактирующими жидкими фазами в сторону фазы с меньшим **коэффициентом активности**. В пределе бесконечного разбавления это γ∞. Для каждого растворителя инструмент выдаёт:

- **D — коэффициент распределения**: `D = γ∞(исх.) / γ∞(раств.)` — насколько сильно растворитель извлекает вещество. **Чем выше, тем лучше.**
- **Ёмкость** = `1 / γ∞(раств.)` — сколько вещества удерживает фаза растворителя.
- **γ∞ (растворитель)** — коэффициент активности при бесконечном разбавлении.
- **Селективность** (опц.) = `D(вещество) / D(соэкстракт)` — насколько чисто растворитель предпочитает целевое вещество примеси. `S > 1` — в пользу целевого.

Поскольку D — это *отношение* коэффициентов активности, оно не зависит от температуры плавления вещества: член плавления твёрдого тела сокращается между фазами. Поэтому нужны только σ-профили, а не Tпл.

### Движок

Коэффициенты активности рассчитываются по **COSMO-SAC-dsp** (Hsieh, Lin & Vrabec 2014) — модель COSMO-SAC с поправкой на дисперсию и разделением водородных связей 2010 (без H-связей / гидроксил / прочее). Реализация валидирована до бита по эталонной реализации NIST (Bell et al. 2020).

### Два режима анализа

- **Быстрый скрининг** *(по умолчанию)* — ранжирует всю библиотеку растворителей за один проход по коэффициентам активности при бесконечном разбавлении (γ∞). Быстро, удобно для первого взгляда на десятки растворителей. Это режим, описанный в разделе «Физика» выше.
- **Двухфазный расчёт** — решает *реальное* жидкость-жидкостное равновесие для настоящего питания (разбавитель + растворитель + вещества). Он отвечает на то, что не может γ∞-ранжирование: образуется ли вообще двухфазное расслоение? Каково истинное распределение каждого вещества при конечной концентрации? Сколько каждого растворителя растворяется в другой фазе? И при какой температуре разделение лучше всего?
- **Оптимизация смеси** — ищет *состав* выбранной смеси из 2–4 растворителей (мультистарт по симплекс-сетке + локальное уточнение, при желании с тёплым стартом по температуре) с рецептом, максимизирующим селективность разделения или распределение целевого вещества. Поскольку целевая функция берётся из полного расчёта, смеси, которые расслоились бы, автоматически отбрасываются. Настроенная смесь часто превосходит любой отдельный растворитель (аналог смешанной оптимизации MINLP из AMS «Optimize LLE»).

### Двухфазный расчёт (строгое ЖЖР)

В этом режиме инструмент формирует питание из разбавителя + каждого растворителя-кандидата (в выбранном мольном соотношении) и ваших веществ (разбавлённых), и для каждого растворителя и каждой температуры в сканируемом диапазоне:

1. выполняет **тест устойчивости по касательной плоскости** (Михельсен), чтобы определить, расслаивается ли смесь на две жидкие фазы вообще — растворители, полностью смешивающиеся с разбавителем, помечаются как *одна фаза* (экстракция невозможна);
2. решает **расчёт по равенству активностей** (Рэчфорд–Райс + метод последовательных подстановок, `K_i = γ_i(рафинат) / γ_i(экстракт)`) для состава **обеих** равновесных фаз;
3. выдаёт **распределение** каждого вещества `D = x(экстракт) / x(рафинат)`, попарную **селективность** `S = D₁ / D₂` целевого над первым дополнительным веществом и **взаимную растворимость** двух растворителей (растворитель-в-рафинате и разбавитель-в-экстракте).

Результаты ранжируются от лучшего — по селективности при двух и более веществах, иначе по D. Вкладка **Двухфазная оптимизация** показывает ранжированную таблицу (растворитель × температура) и полный мольно-долевой состав обеих фаз в лучшей точке; вкладка **Распределение от T** строит зависимость D или селективности от температуры, чтобы выбрать оптимальную температуру экстракции. Чтобы разделить **два или более** веществ, добавьте их в поле *Дополнительное(ые) вещество(а) для разделения*.

### Базы данных соединений

Ключевой вход — **σ-профиль** каждого соединения. Доступны две внутренне согласованные базы:

- **Курируемая (UD)** — 2 259 распространённых растворителей и веществ с **привычными названиями** (квантовая химия DMol3). Для рутинного отбора с обычными растворителями.
- **CHAOS** — 53 088 молекул (Gond et al. 2026, ωB97X-D/def2-TZVP), выбор **по SMILES**. Гораздо более широкий охват, включая сложные, тяжёлые и специальные соединения.

> Две базы используют разные квантово-химические методы, поэтому их коэффициенты активности на немного разных шкалах и **их нельзя сравнивать между базами** — выбирайте одну на ранжирование. Внутри каждой базы ранжирование полностью согласовано.

### FastSigma — любая молекула, даже отсутствующая в базе

В базе **CHAOS** можно **ввести совершенно новый SMILES**, которого нет в каталоге. Встроенная модель **FastSigma** оценит его σ-профиль прямо по структуре (модель машинного обучения, обученная на всех 53 тыс. профилях CHAOS; точность на отложенной выборке ≈ 0,98–0,99 по косинусной близости). Так можно отбирать даже дизайнерские/производные вещества, которых нет ни в одной базе. Дисперсионная энергия и класс водородных связей вычисляются детерминированно по структуре.

### Вкладка «σ-профиль растворённого вещества»

Показывает σ-профиль COSMO-SAC выбранного вещества:

- Для **нового SMILES** строится оценка FastSigma.
- Для соединения, **уже имеющегося в базе CHAOS**, оценка FastSigma **накладывается на истинный профиль** другим цветом — наглядная проверка точности предсказания.

Линии порогов донор/акцептор водородных связей показаны для справки.

### Как пользоваться

1. **База соединений** — Курируемая (по названию) или CHAOS (по SMILES).
2. **Целевое вещество** — выберите из списка или (CHAOS) введите любой SMILES.
3. **Исходная / разбавляющая фаза** — где находится вещество (по умолчанию **вода**).
4. **Температура** — температура экстракции (°C).
5. **Соэкстрагируемое вещество** *(опц.)* — примесь, которую нужно оставить; включает столбец селективности.
6. **Скрининг растворителей** — встроенная библиотека из ~75 распространённых экстрагентов сканируется **автоматически** (ручной выбор не нужен). При желании ограничьте классами растворителей или — только Курируемая база — просканируйте все 2259 соединений.
7. **Запустить отбор.** Результаты ранжируются по **D**: блоки-показатели, таблица, диаграмма и σ-профиль вещества. Кнопка **Экспорт результатов** — полный CSV.

### Примечания и ограничения

- COSMO-SAC — *предсказательная* модель: хорошо отражает тенденции и отбирает кандидатов, но абсолютные γ∞ для сильно ассоциирующих / водных систем могут завышаться. Основной результат — **ранжирование**.
- **Быстрый скрининг** моделирует только поведение в пределе разбавления (γ∞); для настоящего двухфазного расслоения и распределения при конечной концентрации используйте режим **двухфазного расчёта**. Расчёт считает вещества разбавленными в питании (снижайте *мольную долю вещества*, чтобы приблизиться к пределу бесконечного разбавления).
- Профили FastSigma на шкале CHAOS, поэтому сравнение/наложение σ-профилей осмысленно в режиме **CHAOS**; в режиме Курируемая (UD) вкладка показывает только профиль из базы.
