## Фракционирующая колонна

Моделирование **противоточной фракционирующей колонны на сверхкритическом CO₂** с помощью GC(A)-EOS — инструмент проектирования процессов детерпенизации, деацидификации, выделения сквалена и подобных разделений под высоким давлением. Модель — решатель равновесных ступеней по методу Нафтали–Сандхольма (строгий метод одновременной коррекции, устойчивый при больших соотношениях растворителя в СФЭ).

**Растворённые вещества питания**

Отметьте **1–3** растворённых вещества из списка сессии (масло для фракционирования); CO₂ — неявный растворитель. **Загрузить примеры** / **Загрузить с диска** / **Удалить** управляют компонентами сессии. Все вещества должны использовать одну модель УРС.

**Состав питания (масло)**

Мольные (или **массовые**, через флажок) доли растворённых веществ масла без учёта CO₂; их сумма должна быть равна **1**. Иначе значок становится красным и блокирует запуск.

**Параметры колонны**

- **Ступени** — число равновесных ступеней (ступень 1 = верх).
- **Ступень питания** — где входит жидкое питание (масло); ступени ниже образуют укрепляющую секцию.
- **Флегмовое число** — внешняя флегма R/E (0 = без флегмы). Большее значение усиливает разделение.
- **S/F (моль)** — мольное отношение растворителя к питанию (поток CO₂ ÷ поток масла); основной рычаг экстракции.
- **Температура** (°C) и **давление** (бар). Отметьте **температурный градиент** для линейного профиля сверху вниз (создаёт внутреннюю флегму).

**Результаты**

- **Продукты** — статус сходимости, составы **экстракта** (верх) и **рафината** (низ) без растворителя, чистота и расход каждого продукта, а также **извлечение** по каждому веществу (доля, уходящая в экстракт).
- **Профили по ступеням** — мольная доля каждого вещества в жидкости (без растворителя) по высоте колонны (интерактивно; экспортируется).
- **Габариты** — по расходу питания (кг/ч) рассчитываются **диаметр колонны** и **высота насадки** по модели захлёбывания насадочных СФЭ-колонн (Diaz et al. 2005), с плотностями фаз из GC-EOS или по Budich–Brunner.

**Примечания**

- Противоточная конвенция: масло течёт вниз, CO₂ — вверх; **экстракт** уходит сверху, **рафинат** — снизу.
- С общими (поставляемыми) параметрами заданное разделение требует более высокого S/F, чем литературное значение, привязанное к конкретному набору подобранных параметров — увеличьте S/F и/или флегму для более чёткого разделения.
