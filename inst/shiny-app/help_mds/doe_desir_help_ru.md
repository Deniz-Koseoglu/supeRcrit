## Оптимизация желательности DOE

Этот модуль выполняет многооткликовую оптимизацию с помощью **функции желательности Деррингера-Суича** (**Derringer & Suich, 1980**). Находит настройки факторов, одновременно удовлетворяющие целям нескольких откликов из ранее проанализированных моделей DOE.

### Рабочий процесс

**1. Выбор анализов:** Выберите сохранённые результаты анализа DOE с подогнанной моделью для каждого отклика.

**2. Настройки желательности:** Для каждого отклика задайте цель (максимизация, минимизация или целевое значение), допустимый диапазон и весовой коэффициент.

**3. Диапазоны факторов:** Определите область поиска для каждого фактора.

**4. Оптимизация:** Оптимизатор ищет настройки, максимизирующие **общую желательность** *D*:

$$D = \left(\prod_{i=1}^{n} d_i^{w_i}\right)^{1/\sum w_i}$$

где *d*ᵢ — индивидуальная желательность (0–1), *w*ᵢ — вес *i*-го отклика.
