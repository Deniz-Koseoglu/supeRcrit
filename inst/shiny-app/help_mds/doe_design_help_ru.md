## Планирование эксперимента (DOE) — Генерация планов

Этот модуль генерирует экспериментальные планы для систематического исследования параметров процесса. Матрица плана задаёт условия каждого опыта для выполнения в лаборатории и анализа в модуле анализа DOE.

### Доступные типы планов

**Box-Behnken (BBD)** — план поверхности отклика для 3–4 факторов. Три уровня на фактор, без угловых точек, что делает его эффективным, когда следует избегать экстремальных комбинаций.

**Центральный композиционный (CCD)** — план поверхности отклика для 2–4 факторов. Описной (CCC) — звёздные точки за пределами диапазона (±1.414, 5 уровней). Гранецентрированный (CCF) — звёздные точки на гранях (±1.0, 3 уровня).

**Полный факторный (FFD)** — все комбинации уровней факторов. 2–5 факторов при 2 уровнях или 2–3 фактора при 3 уровнях. Планы с 3 уровнями включают 3 центральные точки по умолчанию.

**Дробный факторный (FrFD)** — подмножество полного факторного, требует меньше опытов, сохраняя возможность оценки главных эффектов. 3–5 факторов с настраиваемым дроблением и смешиванием.

**Метод Тагучи (TM)** — ортогональные массивы для робастного проектирования параметров с 3–5 факторами при 2–4 уровнях. Направлен на минимизацию разброса, а не оптимизацию среднего отклика.

### Центральные точки

Дополнительные центральные точки можно добавить к любому плану для обнаружения кривизны (нелинейных эффектов) и оценки чистой экспериментальной ошибки. Это опыты, проводимые в средней точке всех диапазонов факторов.
